# Personal Portfolio - Soumyadeep Paul

Welcome to my personal portfolio project! This responsive and interactive website showcases my skills, education, and projects.

## Overview
This is a modern web application built with React and Vite. It serves as my digital resume, highlighting my journey in software development and my technical capabilities.

## Features
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Modern UI**: Clean and intuitive interface designed for a great user experience.
- **Component-Based Architecture**: Built using modular React components for maintainability.

## Technologies Used
- React
- Vite
- HTML5 / CSS3 / JavaScript

## Setup Instructions

To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/soumyadeep231001102218/assignment-1-portfolio.git
   ```

2. Navigate into the project directory:
   ```bash
   cd assignment-1-portfolio
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit the live site at: [https://soumyadeep231001102218.github.io/assignment-1-portfolio/](https://soumyadeep231001102218.github.io/assignment-1-portfolio/)
